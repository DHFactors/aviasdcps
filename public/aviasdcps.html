📘 How Tenants Compare to State Baseline

ICAO SSP comparison methodology — from State target to tenant action.

  1. State defines ALoSP target and SPI/SPT baselines (SSP)
  2. Tenants declare their SPIs/SPTs (SMS) — see Declare SPIs tab
  3. Tenants submit data via MIRS — mandatory safety data
  4. State aggregates data across ALL tenants — total 10 hazards, avg HRC/SPT/ALoSP
  5. State calculates State Risk Matrix & ALoSP — aggregated risk distribution
  6. Tenants compare internal metrics vs. State baseline — variance columns above
  7. Tenants adjust mitigations based on variance — green (better) vs red (worse)
